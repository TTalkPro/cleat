# cleat-136 运行时签名批次回收与逐出

- 里程碑：M14　依赖：cleat-135　状态：未开始
- 设计依据：[26 §5](../designs/26-runtime-signature-tables.md)

## 问题

cleat-135 已限制每函数 8 个签名、进程 4096 个生成程序集，但 `__rtSpec` 持有特化 IFn 时，
`RunAndCollect` 程序集不会实际回收。长期多态站点仍可能到达进程预算上限。

## 方案草案

1. 签名表记录频率 / 时间戳，支持标记逐出。
2. 批次装载运行时生成的程序集；整批失效后清除引用并 `AssemblyLoadContext.Unload`。
3. 用 GC 到达性测试确认程序集与 JIT 代码可回收。
4. 压力测试多态站点，量化表扫描和 miss 后通用体成本。

## 验收

- 达到逐出条件后旧签名回通用体，热签名可重新生成。
- `Unload` 后 GC 可回收批次上下文。
- 默认与禁用优化语义输出逐字相同；Core / Host 专项通过。

# cleat-136 运行时签名回收与逐出

- 里程碑：M14　依赖：cleat-135　状态：完成
- 设计依据：[26 §5](../designs/26-runtime-signature-tables.md)

## 问题

cleat-135 已限制每函数 8 个签名、进程 4096 个生成程序集，但 `__rtSpec` 持有特化 IFn 时，
`RunAndCollect` 程序集不会实际回收。长期多态站点仍可能到达进程预算上限。

## 方案草案

1. 签名表记录命中次数和最近使用时间；表满时按 LRU 逐出空闲签名。
2. 运行时生成的程序集已是独立 `RunAndCollect`；首版不引入批量 ALC，只移除签名表强引用。
3. 逐出程序集登记 `WeakReference` 诊断，并用 GC 到达性测试确认可回收。
4. 补表满换入、旧签名重建和活跃签名保留测试。

## 验收

- 达到逐出条件后旧签名先回通用体，再按需重新生成；活跃签名继续命中。
- 逐出并强制 GC 后，`AliveRetiredAssemblies` 归零。
- 默认与禁用优化语义输出逐字相同；Core / Host 专项通过。
